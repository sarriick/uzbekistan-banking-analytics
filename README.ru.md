# Аналитика банков Узбекистана

Завершённое исследование банковского сектора за **2024–2025 годы**: сбор первичных данных ЦБ, проверка, SQL-расчёты, интерактивный дашборд и семь подтверждённых выводов.

**Масштаб:** 56 публикаций ЦБ, 25 месячных срезов, 889 наблюдений «банк × месяц», 36 банков за весь период. На каждой дате — 35 или 36 банков. Период: **01.01.2024 — 01.01.2026**.

[Репозиторий GitHub](https://github.com/sarriick/uzbekistan-banking-analytics) · [Выводы с источниками](reports/findings.ru.md) · [Методика](docs/methodology.md) · [Словарь данных](docs/data_dictionary.md)

## Главные результаты

- Депозиты за 2025 год выросли на **35,2%**, после корректировки на ИПЦ — на **26,0%**. Сумовые остатки дали **90,9%** прироста; в отдельном клиентском разрезе юридические лица дали **65,0%**.
- Агрегированный запас ликвидности увеличился: **LCR — 207,5%, NSFR — 119,9%**, оба выше опубликованного ЦБ минимума 100%.
- Доля пяти крупнейших банков в активах снизилась с **57,4% до 50,8%**. Активы вне первоначальной пятёрки выросли на **64,7%**, внутри неё — на **24,8%**.
- Снижение государственной доли разложено на **−4,21 п.п.** от относительной динамики активов и **−0,06 п.п.** от перехода Poytaxt Bank между группами.
- **Octobank** лидировал по приросту доли депозитов, **Agrobank** — по абсолютному приросту, **Kapitalbank** — по объёму средств физических лиц.
- Депозиты составляли **42,1% обязательств госбанков** и **72,1% обязательств остальных банков**. В целом по сектору они обеспечили **80,5% прироста обязательств** за 2025 год.

Каждый результат в [аналитической записке](reports/findings.ru.md) содержит расчёт, конечный вывод и ссылки на первоисточники.

## Как посмотреть

1. Прочитайте [аналитическую записку](reports/findings.ru.md).
2. Скачайте [интерактивный HTML-отчёт](reports/overview.html) и откройте в браузере. Шесть графиков работают без Python и интернета. GitHub показывает исходный HTML; для просмотра нужен скачанный файл.
3. Запустите Streamlit для сравнения банков, выбора дат и выгрузки CSV.

В приложении пять вкладок: обзор рынка, сравнение банков, кредиты и депозиты, выводы исследования, данные и методика. Вкладка исследования показывает итог за фиксированный период 2024–2025; остальные вкладки работают с выбранной датой.

## Запуск на Windows

Откройте PowerShell в папке проекта. Проверенная версия — Python 3.12.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m uzbank.build
.\.venv\Scripts\python.exe -m uzbank.report
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Откройте адрес, напечатанный Streamlit. Сборка, генерация отчёта и тесты используют сохранённые источники. Обращение к ЦБ выполняется отдельно командой загрузчика, описанной в [английском README](README.md).

## Что реализовано

- Архив 50 месячных и 6 дополнительных публикаций с URL, датами получения и SHA-256.
- Python ETL: разбор таблиц, сопоставление названий банков, контроль дат, единиц и округления.
- DuckDB и SQL: доли рынка, календарный рост, CR5/HHI, вклад в прирост, структура обязательств и разложение изменения государственной доли.
- **764 сверки** с опубликованными итогами и балансовыми равенствами, тесты расчётов и управления приложением.
- Генерация одной версии выводов для Markdown, HTML и Streamlit.
- GitHub Actions: сборка, тесты и проверка совпадения опубликованных данных и выводов с результатами пересчёта.

## Как представить проект на собеседовании

«Я исследовал изменение банковского рынка Узбекистана за 2024–2025 годы на данных ЦБ. Собрал 56 публикаций, нормализовал названия банков и воспроизвёл расчёты в SQL. Установил, какие сегменты обеспечили рост депозитов, подтвердил увеличение агрегированного запаса ликвидности и отделил изменение объёмов активов от перехода банка между группами собственности».

Покажите один полный путь: исходная публикация → проверенная таблица → SQL-формула → график → вывод. Например, прирост сумовых депозитов **98,688 трлн сум / 108,566 трлн сум = 90,9%** общего прироста. Затем продемонстрируйте различие между лидером прироста доли рынка и лидером абсолютного прироста.

## Источники и лицензия

Источник — **Центральный банк Республики Узбекистан**. Методика использует статистический периметр коммерческих банков и отдельно определяет балансовый и регулятивный капитал. Код и оригинальная документация распространяются по [MIT](LICENSE); атрибуция первичных публикаций сохранена в [описании данных](data/README.md).
